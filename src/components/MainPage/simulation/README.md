# MQTT Simulation

This folder contains utilities for simulating MQTT message processing in the livestock monitoring system.

## Files

- `mqttSimulator.ts` - Core simulation utilities and classes
- `testSimulation.ts` - Testing utilities for verifying simulation behavior
- `mockDevices.ts` - Static mock device data (legacy, now using MQTT simulation)
- `mockMqttMessages.ts` - MQTT messages that generate the device scenarios
- `index.ts` - Exports all simulation and mock utilities

## Usage

### Basic Simulation
```typescript
import { simulateMqttScenarioWithService } from './simulation';

// Simulate MQTT messages with existing device service
simulateMqttScenarioWithService(deviceService);
```

### Advanced Simulation
```typescript
import { MqttSimulator } from './simulation';

const simulator = new MqttSimulator();
simulator.simulateScenario();
const devices = simulator.getDeviceService().getActiveDevices();
```

### Testing
```typescript
import { testMqttSimulation } from './simulation';

// Run in browser console
testMqttSimulation();
```

### Mock Data
```typescript
import { MOCK_DEVICES, MOCK_MQTT_MESSAGES } from './simulation';

// Access static mock data (legacy)
const devices = MOCK_DEVICES;

// Access MQTT messages for simulation
const messages = MOCK_MQTT_MESSAGES;
```

## How It Works

The simulation processes MQTT messages in chronological order to recreate realistic device scenarios:

1. **Link Messages** (`livestock/<id>/link`) - Device creation
2. **Data Messages** (`livestock/<id>/data`) - Health data with sensor analysis
3. **Alert Messages** (`livestock/<id>/alert`) - Specific alerts from MQTT

Sensor-related warnings (elevated heart rate, temperature, etc.) are generated by the application logic, not sent via MQTT.

## Integration

The simulation is automatically run on MainPage component mount to populate initial device data, providing a realistic starting state for the application.
